A project used to learn python, html, git and APIs.

The program asks for an animal and returns information of that animal via an html-file.

Firstly, we send the user input that should be an animals name to an API to fetch information
of all animals with that name. That information is stored in a JSON-file.
Then, certain traits are picked, wrapped with html and added to an html file to show the information in a proper way.

If the user input is not found in the data, the user is informed about this.
